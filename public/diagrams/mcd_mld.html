MCD (Modèle Conceptuel - Méthode Merise) & MLD (Modèle Logique - Relationnel)

1. Modèle Conceptuel de Données (MCD) Méthode Merise
Entité
Association (Relation)
Souligné Identifiant / Clé Primaire
(0,n) / (1,1) Cardinalités
2. Modèle Logique de Données (MLD - Relationnel) Structure SQL
PK Primary Key (Clé primaire)
FK Foreign Key (Clé étrangère #)
users Utilisateurs
PKid BIGINT AUTO_INCREMENT
nameVARCHAR(255)
emailVARCHAR(255) UNIQUE
passwordVARCHAR(255)
roleENUM('apprenant','tuteur','admin')
telephoneVARCHAR(20) NULL
matiereVARCHAR(255) NULL
bioTEXT NULL
tarif_horaireDECIMAL(8,2) NULL
is_activeBOOLEAN DEFAULT TRUE
timestampscreated_at, updated_at
demandes Besoins de cours
PKid BIGINT AUTO_INCREMENT
FK#apprenant_id users(id)
matiereVARCHAR(255)
niveauVARCHAR(100)
descriptionTEXT
budgetDECIMAL(8,2)
statutENUM('en_attente_moderation','ouverte','en_cours','terminee','refusee')
motif_refusVARCHAR(255) NULL
timestampscreated_at, updated_at
offres Candidatures tuteurs
PKid BIGINT AUTO_INCREMENT
FK#demande_id demandes(id)
FK#tuteur_id users(id)
messageTEXT
tarif_proposeDECIMAL(8,2)
statutENUM('en_attente','acceptee','refusee')
coordonnees_visiblesBOOLEAN DEFAULT FALSE
timestampscreated_at, updated_at
avis Évaluations
PKid BIGINT AUTO_INCREMENT
FK#demande_id demandes(id)
FK#apprenant_id users(id)
FK#tuteur_id users(id)
noteTINYINT (1 à 5)
commentaireTEXT
timestampscreated_at, updated_at
commentaires Discussions
PKid BIGINT AUTO_INCREMENT
FK#demande_id demandes(id)
FK#user_id users(id)
FK#offre_id offres(id) NULL
contenuTEXT
timestampscreated_at, updated_at
notifications Alertes système
PKid CHAR(36) UUID
typeVARCHAR(255)
FK#notifiable_id users(id)
notifiable_typeVARCHAR(255)
dataTEXT (JSON)
read_atTIMESTAMP NULL
timestampscreated_at, updated_at

Écriture Textuelle Universelle (Pour Rapport & Mémoire) :

USERS (id, name, email, password, role, telephone, matiere, bio, tarif_horaire, is_active, created_at, updated_at);

DEMANDES (id, #apprenant_id, matiere, niveau, description, budget, statut, motif_refus, created_at, updated_at);

OFFRES (id, #demande_id, #tuteur_id, message, tarif_propose, statut, coordonnees_visibles, created_at, updated_at);

AVIS (id, #demande_id, #apprenant_id, #tuteur_id, note, commentaire, created_at, updated_at);

COMMENTAIRES (id, #demande_id, #user_id, #offre_id, contenu, created_at, updated_at);

NOTIFICATIONS (id, type, notifiable_type, #notifiable_id, data, read_at, created_at, updated_at);
